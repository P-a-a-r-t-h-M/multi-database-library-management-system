# Multi-Database Library Management System

## Project Overview

The Multi-Database Library Management System was developed as part of the Database Systems module.

This project demonstrates the implementation of three database paradigms:

- Relational Databases (Oracle SQL)
- NoSQL Databases (MongoDB)
- Graph Databases (Neo4j)

The system models a library environment and manages information relating to books, authors, members, borrowing activities, and library operations.

---

## Features Implemented

### Oracle SQL

- Database schema creation
- Table creation
- Primary and foreign key implementation
- Data insertion
- Stored procedures
- Database queries
- View creation

### MongoDB

- Collection design
- JSON document storage
- Data insertion
- Query execution
- Library record management
- Borrowing history management

### Neo4j

- Graph database modelling
- Node creation
- Relationship mapping
- Author-book relationships
- Member-book borrowing relationships
